# Proyecto Integrador: Formulario de Login

## Estrategia de Ramificación Elegida
En este proyecto se utiliza la estrategia **GitHub Flow**.

### Justificación:
GitHub Flow es una estrategia ligera y orientada a despliegues continuos, ideal para proyectos web. Permite mantener la rama principal (`main`) siempre estable y funcional, mientras que cualquier nueva funcionalidad o corrección se desarrolla en ramas de vida corta (`feature/*`). La integración se realiza mediante Pull Requests con revisión de código y validación automatizada por CI, garantizando la calidad antes de fusionar a la rama principal.
